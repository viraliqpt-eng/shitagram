SHITAGRAM™ vClean11.2 — Preferências de privacidade

Ficheiros:
- app_shitagram_clean_v11_2_privacy_preferences.html
- supabase_shitagram_clean_v11_2_privacy_preferences.sql

Como aplicar:
1. Executa o SQL no Supabase.
2. Renomeia app_shitagram_clean_v11_2_privacy_preferences.html para app.html.
3. Faz commit no GitHub.
4. Abre a app com Ctrl + F5.
5. Entra com uma conta aprovada.
6. Abre Privacidade.

O que testar:
- permitir mensagens de Todos;
- permitir mensagens de Só quem sigo;
- permitir mensagens de Ninguém;
- perfil público/privado;
- esconder país/cidade;
- esconder atividade/XP;
- bloquear convites de desconhecidos;
- tentar enviar mensagem entre duas contas com preferências diferentes.

Notas:
- Esta versão mantém mensagens privadas reais.
- O botão Privacidade é adicionado ao desktop e ao mobile.
- A função start_conversation passa a respeitar bloqueios e preferências de mensagens.

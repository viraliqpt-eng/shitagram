SHITAGRAM™ vClean10.3 — Mood Map MVP

Aplicação:
1. Executar supabase_shitagram_clean_v10_3_mood_map.sql no Supabase.
2. Substituir app.html por app_shitagram_clean_v10_3_mood_map.html.
3. Manter index.html como landing pública.
4. Testar login, publicar, reagir, comentar, enviar presente e aplicar boost.
5. Clicar no botão flutuante 🌍 para abrir o Mood Map.

O Mood Map usa dados agregados das últimas 24h:
- país
- cidade
- mood dominante
- percentagem
- ranking emocional por cidade

Não usa localização exata. O país/cidade é guardado localmente no navegador.

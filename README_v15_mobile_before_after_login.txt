v15 — Nova experiência mobile antes/depois do login

Ficheiro:
- app_v15_mobile_before_after_login.html

O que esta versão aplica:
- experiência mobile semelhante à imagem enviada;
- antes do login:
  1. boas-vindas
  2. criar conta
  3. entrar
  4. explorar opcional
- depois do login:
  - Feed
  - ShitClips™
  - Publicar
  - Ranking
  - Perfil
- visual preto/amarelo;
- navegação inferior mobile;
- mockups automáticos em desktop;
- Supabase Auth mantido para email/password;
- sem mensagens técnicas como “Conta demo local” ou “Liga o Supabase”.

Como aplicar:
1. Substitui app.html por app_v15_mobile_before_after_login.html.
2. Faz commit no GitHub.
3. Abre https://shitagram.pt/app.html com Ctrl+F5.
4. Testa em mobile:
   - Começar
   - Criar conta
   - Entrar
   - Explorar sem conta
   - Feed
   - Publicar
   - Ranking
   - Perfil

Notas:
- Publicar ainda fica em modo beta visual.
- Guardar posts reais no Supabase pode ser o próximo módulo.

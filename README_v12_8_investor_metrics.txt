vClean12.8 — Investor Metrics Dashboard

Ficheiros:
- investor_metrics_shitagram_v12_8.html
- supabase_shitagram_v12_8_investor_metrics.sql
- README_v12_8_investor_metrics.txt

Como aplicar:
1. Executa supabase_shitagram_v12_8_investor_metrics.sql no Supabase.
2. No GitHub, renomeia investor_metrics_shitagram_v12_8.html para investor_metrics.html.
3. Abre /shitagram/investor_metrics.html.
4. Entra com uma conta admin/moderator, se necessário.

O dashboard mostra:
- beta signups;
- utilizadores aprovados;
- Premium ativos;
- interessados Premium;
- posts;
- comentários;
- reações;
- Mood Map events;
- denúncias abertas;
- ações admin;
- projeções de receita a 1%, 3% e 5%.

Nota:
A função get_investor_metrics exige utilizador autenticado admin/moderator.

v14 — Landing pública com Arena Live

Ficheiro:
- index_shitagram_v14_public_arena.html

O que esta versão muda:
- posiciona o SHITAGRAM™ como aberto ao público;
- remove foco em candidatura beta;
- CTA principal passa para “Criar conta grátis”;
- inclui Arena Live;
- apresenta o fluxo:
  1. Cria conta
  2. Publica e reage
  3. Entra na Arena
- aponta botões principais para app.html e arena.html.

Atenção:
Só aplica esta versão se a app já estiver pronta para registo público sem aprovação beta.
Se ainda quiseres controlar entradas, mantém a versão beta e muda apenas a copy para “beta fechada”.

Como aplicar:
1. No GitHub, substitui index.html por index_shitagram_v14_public_arena.html.
2. Confirma que app.html permite criar conta.
3. Confirma que arena.html existe.
4. Faz commit.
5. Testa:
   - https://shitagram.pt
   - https://shitagram.pt/app.html
   - https://shitagram.pt/arena.html

Não precisa de SQL novo se a Arena e o registo público já existirem.
